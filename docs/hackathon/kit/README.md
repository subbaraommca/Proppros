# Ship AI workshop kit

Practical AI, Built Together.

## Start with one bot

Open Product Manager from bots.json. Attach this kit and use start-project.md. The bot asks three simple business questions, researches unknowns with the team and keeps your information, positioning, product requirements, design and deliverables in ONE shared brief. Participants do not fill a technical form or coordinate specialists themselves. Add the next role when needed. Use setup-prompt.md with Dr Eggbot only if you want the full team prepared at once; reuse existing roles.

## Four connected breakouts

1. Position and research: clarify the customer, offer and pricing using dated sources. Review the recommendation.
2. Productize the site: PM + Designer choose a useful visitor experience, copy and scope. Review the plan.
3. Design and build: Frontend + Designer build and check it; Backend joins only when needed. Try the actual preview and give feedback.

4. Create your marketing: after site approval, use marketing-handoff.md. Social Media Manager coordinates Performance Marketer plus the Design and Video creators. Start from the approved site/brief, never a second questionnaire. See marketing-bots.json for the existing templates. No post, upload, schedule, ad spend or connection is authorized by this kit.

All prompts are business, brand, audience, presenter, model and provider agnostic. Adapt to B2B/B2C/mixed buying contexts, products or services. No fixed client, industry, city, quote CTA, price or personal presenter persona is part of the workflow. Research and the owner choose the real offer and next action.

## Next.js starter

starter/ is a complete editable Next.js App Router codebase with a pinned lockfile, home/About, article and data-driven solution templates, real local example interaction, metadata/robots/sitemap, and review gates. business-site-starter.zip contains the same source. Read starter/README.md and AGENTS.md. Run npm ci, npm run check, npm run configure, npm run dev. No extra account or API key is needed for a local preview.

The bot fills starter/brief/project.json with intake, sourced positioning and PM work. Configuration generates content/site.json and .agents/product-marketing.md. The two examples/ fixtures are explicitly fictional tests; never ship them as a real business. Draft content is unavailable until reviewed. Indexing remains disabled without owner-approved publication and a real domain. The bot must tailor the design and implement any real signup, booking, purchase or lead response; the starter does not claim these actions work.

The full user-supplied YC Interface Craft skill is in skills/yc-interface-craft/ and starter/.agents/skills/yc-interface-craft/. The Designer loads its actual SKILL.md, four guidance references and research index. For a new business or substantial visual exploration, it presents five comparable directions, recommends one, and waits for the owner’s selection before the final system. Existing approved directions and small fixes do not restart exploration. The research snapshot is October 16, 2026; it is not YC endorsement or a conversion guarantee. File hashes are in designer-skill-manifest.json.

## Project scope

Use only the project folder and processes created for this task. Record the PID, command and working folder of each preview server you start. Stop only a recorded process that this task started. Never stop processes by port or broad name. If a port is busy, use another free port. Do not change another project. Save each approval in the one shared brief, increase its version, and send the path and version to each specialist. Each specialist must read that version before acting. Do not ask the owner to repeat an approval because a local copy is old.


## Shared design skills

Product Designer and Frontend Engineer use the same actual design skill library, versions and reference files. Both load YC Interface Craft with all seven supplied files; Intentional UI Design; Illustration Design Grammar; Emil design engineering and relevant animation skills; frontend-design; product-marketing; lead-magnets; copywriting; copy-editing; and conversion guidance. Keep the full files available in the shared project. A link or summary is not a loaded skill. Use design-skill-library.json to compare file hashes and preserve licenses. Read the instructions relevant to the current web task; do not load unrelated native-app guidance. Frontend keeps its engineering, SEO, build and test skills as well. It implements the selected type, spacing, color, imagery, interaction and motion rules with the Designer. Do not invent a new direction or repeat exploration after approval. Record the loaded paths, versions and hashes in team evidence and send an acknowledgment to the PM. Review the actual implementation together and fix differences before owner review.
