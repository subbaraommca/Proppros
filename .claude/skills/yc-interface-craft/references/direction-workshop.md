# Five-direction workshop

## Find a visual idea specific to the business

Start with the transformation, not a trend board. List objects, documents, workflows, environments, and outputs native to the work. Choose an observable verb: reconcile, assemble, reveal, route, protect, coach, simulate, or compose. Ask what the user should understand from the visual before reading the paragraph.

Examples of generative reasoning, not presets:
- Reconciliation can align mismatched ledger marks into a precise shared baseline.
- A tutoring product can reveal a path of mastered concepts rather than decorate with graduation caps.
- An orchestration product can show a meaningful handoff, including failure and recovery, instead of random particles.
- A human service can use documentary portraits and specific artifacts to make responsibility tangible.

Place the business on useful axes: institutional ↔ personal; quiet ↔ energetic; engineered ↔ organic; literal ↔ metaphorical. Translate positions into decisions, not labels.

## Build an intentionally broad set

The five should usually include a restrained option, a product-native demonstration, a human/material option, an expressive option, and a credible challenge to category conventions. These are breadth checks, not fixed names or a requirement to force irrelevant styles. Five equally plausible business ideas can be better.

Make each pair differ on at least three consequential dimensions: metaphor, spatial composition, type character, image/illustration grammar, or motion behavior. Palette changes alone do not count. At least one must work without animation, and at least one must concentrate expression in genuine product output.

Use the same content and task so comparison is fair. Do not make the preferred option artificially richer. Avoid fake metrics, testimonials, and customer logos; label example content.

## Direction card

Use the following as a completeness aid, not a rigid presentation template:

**Name / premise.** One business-specific sentence. Explain the desired perception and why it matters.

**Hero or primary screen.** Describe exact hierarchy and a visual event: where the headline sits, how large the primary object is, where the task begins, what proof appears, and how the composition continues below the fold. For apps, show the core task instead of inventing a hero.

**Type.** Show the real headline, a paragraph, a button label, and numeric/data examples. Name role, weight, width, case, tracking, and line-height intent. Explain the expressive vs functional relationship. Offer an available fallback, not a disconnected font shopping list.

**Color.** Provide suggested hex/OKLCH values for canvas, raised surface, primary text, secondary text, action, accent, and status roles. A palette is provisional until contrast is checked on the combinations actually used. Show proportions and one dark/light adaptation only if needed.

**Graphic grammar.** Specify form, edge, crop, repetition, topology, density, and scale. One signature family is more useful than unrelated motifs. Explain which elements are compositional and which communicate information.

**Image and material.** Give a concrete art brief: subject, action, perspective, lighting, medium, palette, background, texture scale, and placement. Define an asset family, not a single heroic image that cannot extend. For no imagery, specify how type and space carry the concept.

**Motion.** Storyboard one useful transition. Name trigger → initial state → transition → final state; interruption/reversal; keyboard/touch equivalent; reduced-motion alternative. Distinguish product feedback from ambient storytelling.

**Extension.** Show a representative feature card, data row or task panel, and mobile composition. Keep the same brand idea while changing density and hierarchy appropriately.

**Tradeoff.** One strategic strength, one failure mode, and an honest asset/performance/engineering cost.

## Comparison and decision

Compare strategic fit, clarity, distinctiveness, cross-surface coherence, usability, and feasibility with a one-sentence rationale each. Optional 1–5 ratings are editorial judgments, not conversion data. Weight fit and comprehension more heavily than spectacle.

Recommend one lead and at most one compatible supporting idea. State the tradeoff. Then ask the user to select before finalizing tokens or changing the production interface. If two directions tie, explain the decision criterion instead of presenting false precision.

## After selection

Write a short decision record: selected direction; requested combination; retained brand equity; rejected clichés; three governing rules; unresolved assets. Iterate within it. Reopen exploration only when the user changes the brief or evidence invalidates the premise.
