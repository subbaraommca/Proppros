Proppros keeps rent, leases, tenants, maintenance and money for your rentals in one place. Set it up once and the daily automation does the routine work.

## Set up in four steps

1. **Add your properties.** Go to **Properties → Add property**. Single-family homes, condos and townhouses get a unit called “Main” automatically; for duplexes and apartment buildings, add each unit.
2. **Add your tenants.** **Tenants → Add tenant**. An email address lets them receive receipts, reminders and a portal invitation.
3. **Create leases.** **Leases → New lease**: pick the unit and tenants, set rent, due day, deposit and late-fee rules. For a lease that's already running, tick *This lease is already in progress* and enter what's owed today as the opening balance.
4. **Invite tenants to the portal.** On a tenant's page, click **Invite to portal**. If email isn't set up, copy the link and send it by text.

## What happens automatically

Every morning Proppros:

- posts rent and recurring charges on each lease's due date
- adds late fees once the grace period passes and a balance remains
- emails rent reminders (3 days before, on the due date, and when overdue)
- alerts you 90, 60 and 30 days before a lease ends, and before documents expire

You can run it any time from **Settings → Portfolio → Run today's automation now**. Running it twice never duplicates a charge.
