Invite people to help run your portfolio from **Settings → Team**.

| Role | Can do |
|---|---|
| **Owner** | Everything, including billing, team and payment settings |
| **Manager** | Run properties, tenants, leases, payments, expenses and maintenance |
| **Accountant** | Read-only access to finances, reports and documents |
| **Maintenance** | See properties and work orders; update work orders assigned to them |

## Limiting access to some properties

When inviting a manager, accountant or maintenance person you can choose **specific properties**. They'll only see those properties — and the leases, tenants, payments, expenses, work orders, documents and report figures that belong to them. Change it any time from the member list.

Team-wide actions (inviting people, the audit log, billing and running the automation) need access to **all properties**.
